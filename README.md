# Task Management
This repository contains documentation for the Task Management solutions, including CNBC, MEBC, Tax, and the core base solution.

The base solution is treated as the primary, evolving product and should be updated with any fixes or features introduced across the other Task Management solutions.

**Included documentation:**
- High‑level design, data model, and solution components
- Application Lifecycle Management (ALM) approach, covering unmanaged development, source control, and managed deployments 
- Runbook guidance for deployment, environment configuration, mailbox onboarding, and operational support
