# Task Management

This repository contains the documentation for the **Task Management** solutions, which includes CNBC, MEBC, Tax and the core base solution.

The base solution is treated as the evolving product which should be updated with any fixes or features applied to the other task management solutions.

**Included documentation:**
- High‑level design, data model and solution components
- ALM approach covering unmanaged development, source control, and managed deployments  
- Runbook guidance for deployment, environment configuration, mailbox onboarding, and operational support
