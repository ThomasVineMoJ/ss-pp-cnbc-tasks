
# User Stories for HMCTS Email Enquiry Management (CNBCTaskManagement)

1. **Receive and Create Tasks from Email Enquiries**
   - As an HMCTS team member, I want incoming email enquiries to automatically create tasks, so that all enquiries are tracked and actioned efficiently.

2. **View and Manage Email Messages**
   - As a user, I want to view all email messages and their attachments, so I can respond to and manage enquiries with full context.

3. **Pick Queue Items**
   - As a user, I want to pick items from the queue, so I can start working on enquiries assigned to my team.

4. **Reply to Enquiries**
   - As a user, I want to reply directly to email enquiries from within the system, so that all correspondence is recorded and streamlined.

5. **Park and Unpark Tasks**
   - As a user, I want to park tasks that cannot be progressed immediately and unpark them when ready, so that I can manage my workload and priorities effectively.

6. **Re-Open Tasks**
   - As a user, I want to re-open closed tasks if further action is required, so that no enquiry is left unresolved.

7. **Download Task Attachments**
   - As a user, I want to download attachments from tasks, so I can review supporting documents related to enquiries.

8. **Move Documents to SharePoint**
   - As a user, I want to move task-related documents to SharePoint, so that files are stored securely and are accessible to authorized users.

9. **Clone Routing Rules**
   - As a system administrator, I want to clone existing routing rules, so I can quickly set up similar rules for new scenarios.

10. **Route and Assign Queue Items**
    - As a user, I want to route queue items to specific users or teams and keep them in the queue, so that enquiries are handled by the right people.

11. **Create and Manage Groups**
    - As a user, I want to create groups for tasks, so I can organize related enquiries and manage them collectively.

12. **Summarize Tasks with Copilot**
    - As a user, I want to generate summaries of tasks using Copilot, so I can quickly understand the status and key details of each enquiry.

13. **Automated Workflows for Task Allocation**
    - As a user, I want tasks to be automatically allocated based on rules and workload, so that enquiries are distributed fairly and efficiently.

14. **Automated Email Processing**
    - As a user, I want the system to process incoming and outgoing emails (e.g., convert to plain text, extract case numbers), so that data is consistent and actionable.


15. **Nightly Email Cleanup**
    - As a system administrator, I want nightly cleanup of email queue items, so that the system remains organized and performant.

---

## Additional User Stories from JavaScript Web Resources

16. **Quickly Create Outbound Emails from Ribbon**
    - As a user, I want to create new outbound emails directly from the ribbon with pre-filled parameters, so I can respond to enquiries more efficiently.

17. **Download the Most Recent Email for a Task**
    - As a user, I want to download the most recent sent or received email related to a task as an .eml file, so I can archive or share correspondence as needed.

18. **Be Notified When Notes Are Added by Others**
    - As a user, I want to be notified when other users add notes to a task, so I am aware of important updates or collaboration on my work items.

19. **Be Warned About Invalid JSON Uploads**
    - As a user, I want to be warned if I attempt to upload a configuration file in an invalid format (e.g., JSONC), so I can correct the file and avoid errors in web form configuration.

## Out-of-the-Box User Stories (Dynamics 365 / Model-Driven App)

16. **Sort and Filter Views**
    - As a user, I want to sort and filter lists of records in views, so I can quickly find the information most relevant to my enquiry or task.

17. **Create New Records**
    - As a user, I want to create new records (such as tasks, emails, or queues), so I can capture new enquiries and actions as they arise.

18. **Update and Edit Records**
    - As a user, I want to update and edit existing records, so I can keep information accurate and up to date.

19. **Save Records**
    - As a user, I want to save changes to records, so that my updates are not lost and are available to other team members.

20. **Send Emails**
    - As a user, I want to send emails directly from the system, so I can communicate with external parties and have a record of correspondence.

21. **View Related Emails**
    - As a user, I want to view all emails related to a record (such as a task or case), so I have full context and history for each enquiry.

22. **Associate and Disassociate Related Records**
    - As a user, I want to link or unlink related records (e.g., link an email to a task), so I can maintain accurate relationships between enquiries and actions.

23. **Delete Records**
    - As a user, I want to delete records that are no longer needed, so I can keep the system clean and relevant.

24. **Personalize Views and Dashboards**
    - As a user, I want to personalize my views and dashboards, so I can focus on the information and metrics most important to my role.

25. **Export Data to Excel**
    - As a user, I want to export lists of records to Excel, so I can analyze or share data outside the system if needed.
